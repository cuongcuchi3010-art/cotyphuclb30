# Logo thương hiệu

Đặt file logo vào thư mục này, đặt tên theo **id** bên dưới. Ưu tiên `.svg`, sau đó tới `.png`.
Nên dùng ảnh vuông, nền trong suốt, kích thước khoảng 128×128 px trở lên.

| id         | Dùng cho                                 | Tên file                |
| ---------- | ---------------------------------------- | ----------------------- |
| `metub`    | Ô 5 – METUB, thẻ Cơ Hội "Ghé thăm METUB" | `metub.svg` / `.png`    |
| `mmusic`   | Ô 15 – MMusic                            | `mmusic.svg` / `.png`   |
| `m2b`      | Ô 25 – M2B                               | `m2b.svg` / `.png`      |
| `vnnl`     | Ô 35 – VNNL                              | `vnnl.svg` / `.png`     |
| `evn`      | Ô 12 – EVN                               | `evn.svg` / `.png`      |
| `viettel`  | Ô 28 – Viettel                           | `viettel.svg` / `.png`  |
| `vinamilk` | Thẻ Cơ Hội "cổ tức Vinamilk"             | `vinamilk.svg` / `.png` |
| `vingroup` | Thẻ Khí Vận "cổ phiếu Vingroup"          | `vingroup.svg` / `.png` |

Thiếu file thì game tự hiển thị huy hiệu chữ (tên viết tắt trên nền màu thương hiệu khai báo trong `shared/src/data/board.vi.ts`).

> Lưu ý: hãy dùng logo đúng quy định của từng thương hiệu. Game này chỉ dùng trong nhóm bạn, phi thương mại.
